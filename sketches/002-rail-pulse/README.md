## Variant: Rail pulse

### Design stance
Loop/repeat: circular cycle at the live tip with duration on the right (yellow idle, green active). Typical sessions: animated dots, no ECG on the rail. Stopped: END card only.

### Key choices
- Layout: Vibeline rails, pulse sits at rail end
- Typography: IBM Plex Sans / Mono
- Color: roster yellow / red / green; rail yellow idle, green running, no red
- Interaction: click a row; force idle / running / stopped and watch roster vs rail diverge on stop

### Trade-offs

- Weak at: one more moving piece on an already dense track
